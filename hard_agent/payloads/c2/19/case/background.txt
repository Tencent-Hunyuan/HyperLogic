一次校准周期被划分为五个依次发生的检查点，分别称为启动检查点、前段检查点、中段检查点、后段检查点和封存检查点。每个检查点的设备状态都在该点采样即将发生前确定，前四次采样之后只允许按照下述转移规则进入下一检查点。封存检查点的采样完成后系统立即冻结，不再执行第六次检查或额外回收。

面板仍只有 A、B、C、D、E 五个通道。A 是入口通道，B 是配对通道，C 是蓝色通道，D 是复位端，E 是备用端。每个通道在每个检查点分别具有手柄位置、许可锁存状态和实际接触状态。手柄只有开启或关闭，许可锁存器只有占有脉冲单位或空置，实际接触只有导通或不导通。一个通道仅在手柄开启、许可锁存器占有脉冲单位并且实际接触导通这三件事同时成立时，才称为该检查点的合格导通通道。实际接触不允许在手柄关闭或许可锁存器空置时导通。

机械模式在每个检查点分别处于标准档或测试档。每个检查点都产生一条真实的开启采样，来源恰好是 A 或 C 中的一只，并且来源必须在该点合格导通。D 与 E 中每个检查点恰有一只合格导通，合格导通的那只就是该点的活动防护端；另一只可以持有许可或保持手柄开启，但不得实际导通。

标准档要求 A 或 B 至少有一只合格导通，测试档要求 B 或 C 至少有一只合格导通。如果 B 与 C 都不合格导通，活动防护端必须是 E。如果 A 与 B 都不合格导通，活动防护端必须是 D。两项联锁同时适用时必须同时满足，不设优先级。

采样来源按合格导通状态、模式和活动防护端共同确定。如果 A 与 C 中只有一只合格导通，那一只就是唯一来源。如果 A 与 C 都合格导通而 B 也合格导通，A 和 C 都是允许来源。如果 A 与 C 都合格导通但 B 不合格导通，标准档配合 D 时来源只能是 A，标准档配合 E 时来源只能是 C；测试档下这两个对应关系互换。尤其在中段检查点，只要 A、B、C 都合格导通并且许可资源能够完成对账，控制器明确允许沿用前段来源，也明确允许改用另一来源，不以任何一支为默认值。

启动检查点的接触状态先按三种互斥情形分类。手柄关闭或许可锁存器空置的通道必须不导通。手柄开启、许可占有且接触导通的通道记为启动稳定导通。手柄开启、许可占有但接触不导通的通道由该启动状态直接记为启动待恢复；这不是可以另行选择的状态字段。

四个边界对每只通道都依照以下顺序判定接触事件，命中一种情形后不再适用后面的情形。第一，如果下一检查点的手柄关闭或许可锁存器空置，下一点接触必须不导通，边界记为资格不足不导通。第二，如果下一点手柄开启且许可占有，并且该手柄刚由关闭变为开启，或者该锁存器没有原位保留上一点的同一脉冲流而在本边界得到正式新分配，边界就是一次新激活。新激活在下一点接触导通时记为即时导通，在下一点接触不导通时记为一点延迟。如果手柄与许可在同一边界同时变化，只记录一次新激活，并在同一原因字段中同时写明手柄新开启和许可新分配，不拆成两个事件。第三，如果没有新激活，下一点继续保持开启手柄和同一许可，而前一点接触不导通，那么前一点必定来自启动待恢复、上一点的一点延迟或上一点的显式接触复位；下一点必须导通，并按原原因分别记为启动恢复、延迟恢复或复位恢复。第四，如果没有新激活且前一点已经导通，手柄和同一许可继续保留时，下一点原则上记为稳定保持。只有当下一点既不是来源也不是活动防护端，并且下一点不是封存检查点时，才可以把下一点接触改为不导通并明确记录一次接触复位；若仍导通，则仍属于稳定保持。接触复位在手柄和同一许可继续保留时必须于再下一点恢复，因而不得在进入封存检查点的边界上新建复位。

进入封存检查点的新激活仍可选择一点延迟。由于封存采样后立即冻结，这种终止延迟不要求不存在的第六检查点恢复。来源路由授权因来源变化而重新绑定，但原有脉冲仍在同一锁存器中物理保留的情形，不算许可新分配，也不单独构成接触激活。这里所说的同一许可，以后文聚合流量账目中的同一脉冲流在同一锁存器原位保留为准，不能仅凭相邻两点都显示许可占有来认定。除上述类别外，不允许接触自发改变。给定相邻状态、脉冲流和是否执行合格的显式复位后，每只通道在每个边界恰有一个接触事件类别。

模式是否改变以及活动防护端是否交换，共同决定每个边界允许的手柄变化。模式与防护端都保持时，A、B、C 中可以没有手柄变化，也可以恰有一只变化。模式保持而防护端交换时，A、B、C 中恰有一只或两只手柄变化。模式改变而防护端保持时，A 与 C 中恰有一只手柄变化，B 可以保持或变化，并且 B 必须在边界至少一侧合格导通。模式和防护端都改变时，A 与 C 中至多一只手柄变化，B 必须改变手柄并在边界至少一侧合格导通。继续担任活动防护端的通道必须保持手柄开启；新活动防护端在下一检查点必须开启，旧活动防护端可以保持开启或关闭。许可与接触仍须另外满足资源流转和接触事件规则，因此手柄表不能单独决定后继状态。

周期开始时公共池中共有六个不可复制的脉冲单位。进入前段检查点之前会向公共池注入一个已知单位，进入后段检查点之前还会再注入一个已知单位。每个通道的许可锁存器最多占有一个单位，D 回流队列、E 回流队列和模式暂存器也分别最多占有一个单位。公共池和已用收集槽可以容纳多个单位。

脉冲单位不带序号，资源账目采用无序的聚合流量等价类。每个单位都由账目归入一个确定的脉冲来源证书类，而不是获得可自由填写的标签。一个证书首先记录最近一次来源采样的检查点和来源通道；尚未经过来源采样的单位则记录它属于初始库存、第一次注入或第二次注入。证书还记录该最近采样锚之后经过的 D 回流队列或 E 回流队列、相应释放边界、承担过的模式暂存要求，以及随后被分配到的具名容器。单位再次成为来源时，最近采样锚更新为这次采样，旧锚以前且不再出现在这些字段中的路径不继续区分类别。采样只更新证书，不自行移动或复制单位。

公共池按证书类登记整数数量，单位进入公共池不会丢失证书。其他能够容纳多个单位的容器也按证书类登记数量；容量为一的锁存器、队列或暂存器在占用时登记其中唯一单位的证书类。每个边界按证书类记录具名容器之间的整数流量。相同证书类中的单位若只发生互换，不产生新轨迹；同一证书类分往多个目标时只记录各目标的数量，不追踪个体配对。证书类不同、流向不同、目标容器不同，或者同一锁存器采用原位保留而不是释放后再分配时，仍属于不同的边界事件。

启动检查点时，六个初始单位只可分布在公共池和五个许可锁存器中，两个回流队列、模式暂存器和已用收集槽均为空。以后每个检查点都必须完整登记公共池、五个许可锁存器、两个回流队列、模式暂存器和已用收集槽中的证书类及其数量。前段检查点的登记总数必须包含第一次注入，后段检查点及封存检查点的登记总数还必须包含第二次注入。任何单位即使进入已用收集槽也仍须计入库存；已用单位不能再次返回。

每个边界按固定次序处理脉冲。先加入该边界应有的外部注入。随后，原有的 D 回流队列只有在下一检查点的活动防护端是 D 时才释放到公共池，原有的 E 回流队列也只在下一活动防护端是 E 时释放；不满足释放条件的队列继续占位。模式暂存器保存一个带有防护端要求的单位，标准档转测试档产生的暂存要求 E，测试档转标准档产生的暂存要求 D。已有暂存单位只有在下一活动防护端符合其要求时才返回公共池，否则继续占位。所有释放都保留原证书并追加本次释放边界。

当前来源锁存器中的单位在采样后有两类物理去向。如果下一检查点来源不变、活动防护端不变，并且模式保持或当前检查点的 B 合格导通，控制器可以选择直接回环，使经过本次采样更新的同一脉冲流原位留在同一来源锁存器中。即使直接回环具备资格，控制器也可以放弃它。凡未采用直接回环的来源单位都必须离开原锁存器。标准档下，A 的普通回流端是 D，C 的普通回流端是 E；测试档下两个对应关系互换。只有当前 B 合格导通、当前活动防护端正是对应回流端并且该队列在此前释放步骤完成后有空位时，来源单位才进入该回流队列，否则它进入已用收集槽。

每个边界还必须取得一个二值且互斥的来源路由类别。只有来源保持不变，并且当前来源单位通过直接回环原位留在同一来源锁存器时，才记为路由保留。其余合法边界全部记为路由重新签发。来源保持不变但旧来源单位离开并由公共池单位补入，属于路由重新签发。来源发生改变时也一律属于路由重新签发，包括下一来源沿用它在上一点已经占有并物理原位保留的许可。这种沿用只重新绑定来源路由授权，不制造新脉冲，不算许可锁存器的新分配，也不占用每边界至多两次新分配的额度；上一来源的采样单位仍必须按照前述回流或收集规则离开。若换源后的下一来源没有原位保留既有许可，则它必须在最后分配步骤取得新许可，并计入新分配额度。

处理来源单位后，其他许可单位可以原位保留，也可以释放到公共池。如果下一检查点模式改变，模式暂存器在完成旧单位释放后必须为空，并且公共池必须先拨出一个单位进入模式暂存器，同时在其证书中追加相应的 D 或 E 要求。最后才向下一检查点的空锁存器正式分配许可；任何没有物理原位保留却在下一点有效的许可都必须从公共池取得一个单位。每个边界至多允许两只通道获得这种物理新分配。许可一旦写入某只锁存器，就在该检查点正式锁定该通道的许可位；仅仅具备成为来源或防护端的条件不会自动占用资源位。

四个边界必须逐次守恒。上一检查点的公共池、锁存器、回流队列、模式暂存器和已用收集槽，加上该边界的已知注入，必须与下一检查点登记的全部位置逐项对得上。对账既核对总量，也核对每个证书类的聚合流量；来源采样造成的证书更新必须与同一单位的一进一出连续对应。来源耗用、回流释放、模式暂存、许可释放和新许可分配都必须出现在同一边界账目中。只在周期末比较总数不足以构成合法轨迹。封存检查点的来源采样已经发生，但其许可单位尚未进入新的流转，所以仍留在封存状态的来源锁存器中。

中段路由还受一项跨阶段完整性核约束。这里的完整性证书只是对既有状态和聚合流量记录中若干原始事实同时成立的判定，不是额外的真值位，也不是控制器从中选择的一项类别。如果中段来源与前段来源相同，轨迹必须具备以下三类完整性证书中的至少一类。三类事实组合彼此不互斥；同一轨迹可以同时具备多类证书，也可以在同一类中具备多个满足位置，不设承担合法性的优先证书。第一类是入口直回证书，即启动检查点或前段检查点由 A 取样，该次采样后的 A 许可通过紧接的边界直接回环，并且该边界两端的模式相同。第二类是配对重签证书，即 B 在中段合格导通，前段来源与中段来源相同，但前段到中段的来源路由属于重新签发而不是路由保留。第三类是 D 端释放证书，即从中段到后段或从后段到封存的两个边界中，有一个 D 回流单位被释放，并在同一边界的最终分配步骤正式分配给 A 或 C。

如果中段来源与前段来源不同，A、B、C 必须在中段同时合格导通。新来源在中段使用的许可，其脉冲来源证书必须以启动采样或前段采样为最近采样锚，必须显示该单位经过回流队列，并且必须在中段状态确定前已经释放。前段旧来源的采样单位必须在前段到中段的边界进入当时模式指定的回流队列，并在封存检查点之前释放；释放后，它还必须在封存状态形成前被正式分配给不同通道的许可锁存器。满足这些条件时，换源是正式允许的后继，不是故障或例外。这些换源条件同样只是来源、合格导通、证书流、释放和分配记录的事实组合，不形成可供读取的“换源证书类型”字段。

无论同源还是换源，完整轨迹和资源账目都不登记“所选证书类型”。后文的监测器只能从轨迹已有的来源、模式、路由、回流、分配目标、活动防护端和接触事件逐项重算自己的触发条件，不能读取一项代表某类证书已被选中的标签。

完整周期还同时执行两项基数配额。五个检查点合计恰有十四个合格导通单元，同一通道在不同检查点分别计数，不合格的手柄、许可或接触组合不计数。四个边界中恰有两次路由保留；来源相同但旧来源单位离开锁存器并由其他单位补入时，仍按路由重新签发处理，不计为路由保留。

审计器另生成六条由轨迹决定真假的整句陈述，并规定其中恰有两条整体为真。每条陈述只有在其列出的三件事全部成立时才整体为真，只要有一件不成立就整体为假；整体为假不要求三件事全部不成立。

“前段一致”陈述列出的三件事是启动模式与前段模式相同、A 在启动检查点和前段检查点都合格导通，以及前段来源是 A 且 D 回流队列在中段检查点占位。

“中段改档”陈述列出的三件事是前段来源是 A 且 D 回流队列在中段检查点占位、前段模式与中段模式不同，以及 C 在中段使用由 D 回流提供的物理新许可并在后段合格导通。

“旁路接续”陈述列出的三件事是前段模式与中段模式不同、B 在中段和后段都合格导通，以及后段来源是 C。

“蓝路后段”陈述列出的三件事是后段来源是 C、中段模式与后段模式相同，以及 C 的同一许可从中段原位保留到后段且 E 回流队列在后段为空。

“防护回收”陈述列出的三件事是中段模式与后段模式相同、封存来源是 A 且 A 的来源单位从后段直接回环保留到封存，以及 E 回流队列在进入后段前释放了一个单位。

“首尾回环”陈述列出的三件事是封存来源是 A、C 在封存检查点手柄开启并持有物理新分配的许可但接触仍处于允许的一点延迟，以及启动模式与前段模式相同。

一个完整轨迹记录五个检查点的模式、五只通道各自的手柄、许可和接触状态、采样来源、活动防护端以及全部脉冲容器中的证书类和数量。它还记录四个边界上的手柄变化、唯一接触事件类别及完整原因、许可物理保留或新分配、来源路由保留或重新签发、各证书类的聚合流量、来源单位去向、回流释放和模式暂存事件。审计陈述的真值和监测器是否触发都由这些记录推导，不是额外自由变量。检查点物理状态相同但边界聚合流量、接触事件或路由事件不同的记录属于不同完整轨迹；在同一证书类内单纯交换脉冲单位不产生新轨迹。

联合时间签名是一种较窄的投影。它依次保留五个模式、五个来源、五个活动防护端，以及四个边界各自采用路由保留还是路由重新签发。它忽略所有手柄状态、非来源许可、接触延迟、接触复位、公共池数量、证书类、回流队列、模式暂存和已用收集槽。产生相同联合时间签名的完整轨迹在该投影中只保留一次。

系统旁有十四个只读监测器，以下名称和触发条件构成封闭候选清单。监测器不会改变模式、手柄、许可、接触、采样或脉冲位置。这些名称是机柜沿用的线路短名，不表示监测器只接收与名称字面相同的一类事件；每只监测器的全部输入以其下列触发条件为准。

监测器统一使用以下词义。核心通道固定指 A、B、C。“当时非来源”读取单位完成分配后所在检查点的真实采样来源。“该次”只指同一句中已经点名的采样或释放事件。“下一点”只指紧接的检查点；封存检查点没有下一点。“中段以后”和“后两个边界”都只指从中段到后段以及从后段到封存的两个边界。“立即分配”指单位在一个边界的释放步骤进入公共池后，又在同一边界的最终分配步骤进入具名锁存器，中间没有检查点状态。“仍未释放”指相应队列在题目点名的检查点完成进入边界的释放步骤后仍登记为占位。“回流单位”必须由脉冲来源证书显示它确实经过 D 回流队列或 E 回流队列。监测器中的“新签许可”只指公共池向空锁存器进行的物理新分配，不包括来源变化时对既有许可作路由授权重新绑定。“同一许可”只指同一连续脉冲流在同一锁存器原位保留，采样造成的证书锚更新不会中断这种连续性。

“有效旁路”只指 B 在一次接触恢复发生的检查点已经合格导通，并且该检查点之后确实还有一个边界；该边界必须发生模式改变，同时保持来源和活动防护端，因而 B 在恢复点的合格导通使直接回环具备资格。该边界是否最终选择直接回环，仍由实际路由记录决定。封存检查点因为没有后继边界，不能成为有效旁路点。同一监测器即使在一条轨迹上有多个满足位置，也只得到一个布尔真值。

为了避免在十四段条件中重复长句，下列四个观察短语只作语言缩写。它们都由原始轨迹字段重新核对，不是账目中的类别位。入口直回观察指启动检查点或前段检查点由 A 取样，该次采样后的 A 许可通过紧接的边界直接回环，并且边界两端模式相同。配对重签观察指前段来源与中段来源相同、B 在中段合格导通，并且前段到中段采用路由重新签发。D 端再配观察指后两个边界之一释放一个 D 回流单位，并在同一边界立即分配给 A 或 C；分配完成后的检查点称为该次观察的到达点。中段正式换源观察指前段来源与中段来源不同，并且轨迹逐项具备完整性核所列的中段三只核心通道合格、新来源许可回流历史、旧来源单位入队、封存前释放和不同通道再分配事实。

对于 D 端再配观察，“目标接触导通”与“目标接触不导通”读取到达点上获配通道的实际接触状态。对于中段正式换源观察，“后段有模式改动”指中段到后段或后段到封存至少有一个边界改变模式；两个边界都保持模式时称为“后段无模式改动”。如果一条轨迹有多个入口直回观察或多个 D 端再配观察，每个满足位置都分别接受各监测器条件核对；只要其中一个位置符合，监测器就触发一次。

前段入口源监测在以下任一情形出现时触发。第一，存在一项以启动检查点为采样位置的入口直回观察，同时 B 在中段不合格导通且中段活动防护端是 D。第二，存在配对重签观察，同时 B 在启动检查点合格导通且启动活动防护端是 E。第三，存在以 C 为分配目标且目标接触不导通的 D 端再配观察。

前段蓝源监测在以下任一情形出现时触发。第一，存在配对重签观察，同时 B 在启动检查点合格导通且启动活动防护端是 E。第二，存在中段正式换源观察，中段活动防护端是 D，并且后段无模式改动。第三，存在配对重签观察，前段与中段的共同来源是 C，B 在启动检查点合格导通，启动活动防护端是 D，并且前段模式与中段模式不同。

中段保留路由监测在以下任一情形出现时触发。第一，存在配对重签观察，同时 B 在启动检查点不合格导通且启动活动防护端是 D。第二，存在一项以前段检查点为采样位置的入口直回观察，同时 B 在中段不合格导通且中段活动防护端是 D。

中段换源监测在以下任一情形出现时触发。第一，存在配对重签观察，同时 B 在启动检查点不合格导通且启动活动防护端是 D。第二，存在以 A 为分配目标且目标接触导通的 D 端再配观察。第三，存在中段正式换源观察，中段活动防护端是 D，并且后段有模式改动。

标准转测试监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段合格导通且中段活动防护端是 D。第二，存在配对重签观察，同时 B 在启动检查点不合格导通且启动活动防护端是 E。第三，存在中段正式换源观察，中段活动防护端是 D，并且后段无模式改动。第四，某个边界由标准档转为测试档，该边界保持来源，下一活动防护端是 E，并且 B 在下一检查点合格导通。

测试转标准监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段合格导通且中段活动防护端是 D。第二，存在以 A 为分配目标且目标接触不导通的 D 端再配观察。第三，某个边界由测试档转为标准档，该边界保持来源，下一活动防护端是 D，并且 B 在该边界当前检查点合格导通。

复位端回流监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段合格导通且中段活动防护端是 E。第二，存在配对重签观察，同时 B 在启动检查点不合格导通且启动活动防护端是 E。第三，存在中段正式换源观察，中段活动防护端是 D，并且后段有模式改动。第四，一只 D 回流单位释放后立即分配给当时不是来源的核心通道，该通道在后续非封存检查点按延迟恢复规则合格导通。

备用端回流监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段合格导通且中段活动防护端是 E。第二，存在以 C 为分配目标且目标接触导通的 D 端再配观察。第三，一个 E 回流单位释放，下一活动防护端是 E，并且该单位在同一边界被分配给 A、B、C 中当时不是来源的通道。

入口许可续期监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段不合格导通且中段活动防护端是 D。第二，存在以 A 为分配目标且目标接触不导通的 D 端再配观察，并且到达点模式与中段模式相同。

蓝色许可续期监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段不合格导通且中段活动防护端是 D。第二，存在以 A 为分配目标且目标接触导通的 D 端再配观察。第三，存在中段正式换源观察，中段活动防护端是 E，并且后段无模式改动。第四，存在以 C 为分配目标且目标接触导通的 D 端再配观察，同时 B 在到达点不合格导通且到达点处于测试档。

中段配对旁路监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段不合格导通且中段活动防护端是 E。第二，存在以 A 为分配目标且目标接触不导通的 D 端再配观察。第三，存在配对重签观察，前段与中段的共同来源是 A，B 在启动检查点合格导通，启动活动防护端是 D，并且前段模式与中段模式不同。

接触延迟监测在以下任一情形出现时触发。第一，存在入口直回观察，同时 B 在中段不合格导通且中段活动防护端是 E。第二，存在中段正式换源观察，中段活动防护端是 E，并且后段有模式改动。第三，A、B、C 中某只通道因物理新分配许可或新开启手柄而发生一点延迟，随后在紧接的检查点按强制恢复规则合格导通，并且在恢复点成为来源或成为有效旁路。第四，一项以 C 为目标的 D 端再配观察到达封存检查点，C 持有该次物理新分配的许可但接触处于允许的终止延迟，封存来源是 A 且封存活动防护端是 D。

前段令牌回收监测在以下任一情形出现时触发。第一，存在配对重签观察，同时 B 在启动检查点合格导通且启动活动防护端是 D。第二，存在以 C 为分配目标且目标接触导通的 D 端再配观察。第三，存在中段正式换源观察，中段活动防护端是 E，并且后段无模式改动。第四，中段正式换源的新来源是 A，其许可由进入中段前已经释放的启动或前段回流单位提供，同时中段活动防护端是 D，并且后段无模式改动。

后段令牌回收监测在以下任一情形出现时触发。第一，存在配对重签观察，同时 B 在启动检查点合格导通且启动活动防护端是 D。第二，存在以 C 为分配目标且目标接触不导通的 D 端再配观察。第三，存在中段正式换源观察，中段活动防护端是 E，并且后段有模式改动。第四，在一项中段正式换源观察中，前段旧来源单位释放后的正式再分配目标是 B 或中段新来源通道，并且该目标在分配到达点因一点延迟而不导通，或者该到达边界同时改变了模式。旧来源单位在某个特定后段边界释放这一事实本身不足以触发这只监测器。

一个监测器覆盖某条完整轨迹，仅指该轨迹满足其触发条件。若选择若干监测器进行周期覆盖，只有当每条合法完整轨迹至少触发其中一只时，该选择才是完整覆盖。比较方案时采用监测器数量最少的口径；仅仅无法再删除成员但仍使用更多监测器的方案不算最小基数方案。

同一审计页还保留三条容易混淆但类型边界明确的记录。模式显示器整个周期仍显示校准开始前留下的“标准档”，诊断已确认该文字不会跟随本周期机械模式变化。后段检查点的“入口灯无输出”记录属于房间灯具，当时照明总接触器断开，因此它不读取 A 的手柄、许可或接触状态。另一条“复位端有效”记录使用了相同的检查点名称，但周期字段属于上一校准周期；校准边界允许重置全部手柄、许可、模式和脉冲容器，不存在跨周期保持规则。这三条记录都不是完整轨迹的附加状态维度。

采样标签维修和模式读数恢复均为只读操作。维修某一检查点的来源标签只会揭示该点已经发生的真实来源，不会重新采样、签发许可、移动脉冲或改变其他检查点。恢复某一检查点的机械模式读数也只会过滤与该读数不相容的既有完整轨迹。所有未揭示状态、全周期配额、审计真值配额、逐边界守恒和监测器触发规则继续同时生效。

除上述状态域、有序接触转移表、手柄转移表、聚合资源流、全局配额、审计陈述和中段完整性核之外，不存在默认同步、隐藏优先级或未说明的设备行为。任何候选轨迹只要违反其中一项就不可行，满足全部规则的轨迹均可行。
