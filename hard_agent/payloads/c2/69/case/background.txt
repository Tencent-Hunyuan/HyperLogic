六月十八日，七号展柜中的珠宝在二十时四十二分至二十时四十三分五十九秒之间被取走。警方确认，盗窃者恰好是 A、B、C、D 四人中的一人，并且没有同伙。盗窃者必须在案发时位于展厅内，必须曾使用本人卡片完成一条合规进入路径，并且必须在案发时亲自接触七号展柜。

审计把相关时间划为五个连续的两分钟窗。第一窗从二十时三十六分开始，第二窗从二十时三十八分开始，第三窗从二十时四十分开始，第四窗从二十时四十二分开始，第五窗从二十时四十四分开始。第四窗是案发窗，第三窗是案发前一窗。受控城市区域包括展厅、两门内外的受控通道和城市侧候行区，但不包括乡下检查站。

A 的永久岗位是乡站管理员，B 的永久岗位是北库领货人，C 的永久岗位是修复师，D 的永久岗位是夜班主管。岗位名称只表示当窗权限所依附的岗位，不是额外人物。第一窗开始时，四人分别履行自己的永久岗位。此后岗位按照四份电子交接单临时交换。第二窗开始时，青交一号要求 A 与 B 或 D 中的一人交换当时所持岗位。第三窗开始时，青交二号要求 C 与 A、B、D 中的一人交换当时所持岗位。第四窗开始时，青交三号要求 B 与 A、C、D 中的一人交换当时所持岗位。第五窗开始时，青交四号要求 D 与 A、B、C 中的一人交换当时所持岗位。每份交接单都必须选择一名列明的接收人，交接双方交换交接前各自所持的岗位，已经完成的交换不会自动撤销。每窗的资格状态先确定，随后处理该窗交接，再处理通行。接收人只有在该窗资格有效时才能完成交接，否则该完整历史不成立。电子岗位交接不要求双方位于同一地点。任何时刻每个岗位都恰有一名持有人，每个人也恰好持有一个当窗岗位。

检查站定位材料确认，A 与 C 中恰有一人连续覆盖第二窗、第三窗和第四窗的乡下检查站值守。检查站距展厅至少九十分钟车程，因此该人也不可能在紧邻的第一窗或第五窗使用展厅门禁，其实名反潜回会话在五个时间窗内始终处于门外池。现有材料不能在 A 与 C 之间进一步区分，也没有默认值或可信度优先级。未在检查站的另外三人五窗内都位于受控城市区域，但其具体处于门外池还是展厅内池，要由实名会话账确定。

每一窗恰有一个完整门禁档生效。损坏的档名来源只留下两条互斥且穷尽的切换序列。甲乙序列在第一窗使用甲档，并从第二窗开始连续使用乙档。丙甲序列在第一窗和第二窗使用丙档，并从第三窗开始连续使用甲档。两条序列不得拼接，也没有第三条序列。

甲档在西门接受北库领货人岗位和修复师岗位，在东门接受乡站管理员岗位和夜班主管岗位。乙档在西门接受修复师岗位和夜班主管岗位，在东门接受乡站管理员岗位和北库领货人岗位。丙档在西门接受乡站管理员岗位、修复师岗位和夜班主管岗位，在东门只接受北库领货人岗位。权限按当窗实际持有的岗位判断，不按永久岗位判断。同一岗位在同一档中只属于一扇门，退出动作与进入动作都必须使用当窗档接受的岗位。

每个人在每一窗的资格状态只能是尚未生效、有效、暂停或过期。暂停可以在后续窗口恢复，过期后不能恢复。完整性校验把每人的当前资格轨迹封闭如下。A 的轨迹有三种：第一种在第一窗尚未生效并在其余四窗有效；第二种在前三窗有效、第四窗暂停、第五窗恢复有效；第三种在前两窗有效、第三窗暂停、后两窗恢复有效。B 的轨迹有四种：第一种五窗均有效；第二种第一窗尚未生效而后四窗有效；第三种前四窗有效而第五窗过期；第四种前两窗有效、第三窗暂停、后两窗恢复有效。C 的轨迹有四种：第一种五窗均有效；第二种第一窗尚未生效而后四窗有效；第三种前两窗有效、第三窗暂停、后两窗恢复有效；第四种前三窗有效、第四窗暂停、第五窗恢复有效。D 的轨迹有三种：第一种第一窗尚未生效而后四窗有效；第二种五窗均有效；第三种前三窗有效、第四窗暂停、第五窗恢复有效。每人必须采用其中一条完整轨迹，不得逐窗拼接不同轨迹。

本人卡片是否可用由另一组封闭轨迹确定。A 可以选择仅第二窗不可用、仅第三窗不可用或仅第五窗不可用的轨迹。B 可以选择五窗均可用、仅第一窗不可用、仅第三窗不可用或仅第四窗不可用的轨迹。C 可以选择五窗均可用，或者第二窗和第五窗不可用而其余三窗可用的轨迹。D 可以选择五窗均可用、仅第二窗不可用或仅第四窗不可用的轨迹。资格有效与卡片可用是两个不同条件；其中一个成立不能替代另一个。

一次成功门禁动作必须同时满足以下条件：动作由本人实名会话承担，本人位于允许发起该动作的一侧，本人卡片当窗可用，本人资格当窗有效，本人持有的岗位已经生效且未受远端岗位隔离，当窗档在所用门接受该岗位，并且反潜回状态允许该次进入或退出。每人每窗至多承担一次进入或一次退出，不能在同一窗同时承担两种动作。每窗的进入先发生，退出后发生；当窗进入者不能承担同窗退出，退出者必须在该窗开始时已经位于门内池。档案切换、岗位交接、资格暂停和卡片不可用都不能重置、复制或转移实名会话。

当前期初快照显示，第一窗开始时恰有一份实名会话在展厅内池，其最近一次成功进入来自东门，但快照没有记录持有人姓名。当前期末快照要求第五窗结束时仍恰有一份实名会话在内池。检查站人物不能成为期初内池会话的持有人。两扇门共享同一组实名会话，任何一次进入都把该人的会话从门外池转入内池，任何一次退出都把同一人的会话转回门外池。

逐窗流量记录不写通行人姓名，但给出了完整的成功动作结构。第一窗有一次西门进入和一次东门退出。第二窗有一次东门进入和一次西门退出。第三窗的两次动作由夜班主管岗位持有人的卡片状态控制；如果该人的卡片在第三窗可用，则第三窗有一次东门进入和一次西门退出，否则第三窗有一次西门进入和一次东门退出。第四窗在二十时四十二分五十四秒有一次西门进入，并在二十时四十三分三十七秒有一次东门退出。第五窗的两次动作由修复师岗位持有人的资格状态控制；如果该人的资格在第五窗有效，则第五窗有一次东门进入和一次西门退出，否则第五窗有一次西门进入和一次东门退出。各窗除此之外没有其他成功进入或退出。

三项同源执行字段还会同时作用于通行、事件关联和核验栏。当前的 B 门别复核字段指定东门，因此 B 如果在第三窗承担成功门禁动作，只能承担东门动作，即使一般档案规则还接受其岗位使用另一扇门也不例外。当前的事件前序窗字段指定第三窗，因此盗窃者只能是第四窗进入者，或者是第三窗进入后在案发时仍处于内池的人。当前的远端岗位隔离字段指定第三窗，因此检查站人物的永久岗位在第三窗不能支持任何门禁动作，也不计作该窗已经生效的在城岗位；该岗位当时由谁持有并不改变隔离效力。

封存清单将本案事件类别限定为柜锁防拆联动，事件编号限定为“珠案四一七”，对象限定为“柜控七号”，封签限定为“蓝封三十一”，时间限定在第四窗内。只有五项全部匹配的控制器行才属于本案事件。通道字段不参与识别事件行，但在事件行确定后，表示盗窃者本人实名会话最近一次成功进入展厅所使用的门。

相关时间范围内共有四条穷尽的控制器候选行。控制行十七形成于二十时四十三分十八秒，事件类别为柜锁防拆联动，事件编号为“珠案四一七”，对象为“柜控七号”，封签为“蓝封三十一”，通道为西门。控制行二十二形成于二十时四十三分二十一秒，对象同为“柜控七号”，但事件类别为维护自检，事件编号为“维检四一七”，封签为“黄封三十一”，通道为西门；维护自检不会开门、转移实名会话或记录人员通行。控制行三十一形成于二十时四十三分十一秒，事件类别、事件编号和封签与封存清单相同，但对象是相邻的“柜控八号”，通道为东门。控制行四十四的事件类别、事件编号、对象和封签都与封存清单相同，但形成于二十时四十六分零三秒，已经超出第四窗，通道为东门。

第四窗的西门进入发生在本案事件之前，东门退出发生在本案事件之后。案发时内池中的人都可能具有与盗窃无关的在场路径，但只有一人实施盗窃接触。盗窃者必须属于事件前序窗字段允许的候选，并且其最近一次成功进入所用门必须与本案事件行的通道字段一致。七号展柜的接触汇总确认，五窗内除这一次盗窃接触外没有其他七号展柜接触，因此柜体接触状态不形成额外自由选择。

四人各填写了一份包含三个断言的复合核验栏。只有一栏中的三个断言全部符合完整历史时，该栏整体才为真；栏内符合的单个断言不单独计数。A 栏的三个断言分别是：第二窗时，检查站人物的永久岗位由另一人持有；第三窗时，B 的卡片可用、资格有效，并且当窗档在 B 门别复核字段指定的东门接受 B 当时持有的岗位；盗窃者就是第四窗的进入者。B 栏的三个断言分别是：第三窗时，C 位于受控城市区域，并且当窗档在西门接受 C 当时持有且未被隔离的岗位；第二窗时，A 的卡片可用且资格有效；盗窃者在第四窗开始时已经位于内池。C 栏的三个断言分别是：第二窗时，A 位于受控城市区域，并且当窗档在东门接受 A 当时持有且未被隔离的岗位；第四窗时，D 的卡片可用且资格有效；事件前序窗字段所指定窗口的进入者就是盗窃者。D 栏的三个断言分别是：在远端岗位隔离字段指定的窗口，检查站人物的永久岗位由另一人持有；第四窗时，C 的卡片可用、资格有效，并且当窗档在西门接受 C 当时持有的岗位；第五窗的进入者不是盗窃者。

所有完整历史必须同时满足四项彼此独立的全局审计规则。第一项是在城有效单元配额：第二窗、第三窗和第四窗合计恰有七个人物时间单元同时满足位于受控城市区域、本人卡片可用、本人资格有效并且所持岗位已经生效且未被隔离。第二项是合规通行人配额：五窗内恰有三名不同人物至少承担过一次符合全部门禁条件的成功进入或退出。第三项是实名会话守恒：期初与期末余额、逐窗进入退出、每人的内外状态以及最近进入门必须连续接续，任何门都不能凭空产生、复制或遗失会话。第四项是整栏真值配额：A 栏、B 栏、C 栏和 D 栏中恰有两栏整体为真。这四项规则与事件匹配、盗窃者本人资格和检查站地点限制一并施加。

修复审计另行封闭了十四个可修复字段。每个字段只有一个当前值和一个唯一修复值；选中某字段时，必须把该字段的全部同源用途一起替换，未选字段保持当前值。第一项“甲乙切换窗”的当前值是从第二窗开始使用乙档，修复值是从第三窗开始使用乙档。第二项“丙甲切换窗”的当前值是从第三窗开始使用甲档，修复值是从第四窗开始使用甲档。第三项“青交二号接收人”的当前值允许 A、B、D 三名候选，修复值只允许 D。第四项“A 资格起始窗”的当前值允许第一窗或第二窗起效，修复值只允许第一窗起效，修复后不得采用第一窗尚未生效的 A 资格轨迹。第五项“B 资格终止窗”的当前值允许资格在第五窗开始前终止或在第五窗后终止，修复值只允许在第五窗后终止，修复后不得采用第五窗过期的 B 资格轨迹。第六项“C 资格暂停窗”的当前值允许不暂停、第三窗暂停或第四窗暂停，修复值只允许第四窗暂停。第七项“D 资格起始窗”的当前值允许第一窗或第二窗起效，修复值只允许第一窗起效，修复后不得采用第一窗尚未生效的 D 资格轨迹。

第八项“第三窗门流极性”的当前值规定夜班主管岗位持有人的卡片可用时由东门进入、从西门退出，修复值把这两种门向对调。第九项“第五窗门流极性”的当前值规定修复师岗位持有人的资格有效时由东门进入、从西门退出，修复值把这两种门向对调。第十项“反潜回首尾余额”的当前值规定期初和期末各有一份内池会话，且期初会话最近来自东门；修复值规定期初和期末各有两份内池会话，期初两份会话分别最近来自西门和东门。第十一项“盗窃事件通道”的当前值是西门，修复值是东门。第十二项“B 门别复核字段”的当前值是东门，修复值是西门；该替换同时改变 B 在第三窗的额外通行限制和 A 栏第二个断言。第十三项“事件前序窗字段”的当前值是第三窗，修复值是第二窗；该替换同时改变事件可关联的前序进入者和 C 栏第三个断言。第十四项“远端岗位隔离字段”的当前值是第三窗，修复值是第二窗；该替换同时改变岗位隔离窗口和 D 栏第一个断言。

任何候选修复都不得直接把盗窃者字段改写为 B，也不得删除全局配额、放松门禁条件或引入新人物、新档案和新通道。修复审计的目标是让修复后的存活历史非空，让 B 成为所有存活历史中的唯一盗窃者，同时让 A 在检查站和 C 在检查站两个身份分支各自至少保留一条历史，并让甲乙序列和丙甲序列也各自至少保留一条历史。比较修复方案时只计算被替换的具名字段数量；每个候选方案都必须从基础状态重新计算岗位、权限、会话、配额、核验栏和盗窃者，不能沿用修复前的派生结果。

一个完整历史由检查站人物、档案切换序列、四份交接单的接收人、四人的资格轨迹、四人的卡片轨迹、期初实名会话持有人、逐窗实名进入退出分配、每窗岗位与内外区域状态以及盗窃者共同确定。如果两个历史在其中任何一项基础事实上不同，就分别计数。门禁是否合规、最近进入门、城市有效单元数、整体为真的核验栏以及是否达到修复目标都是派生事实，不得再次增加重数。除上述候选域、十四个修复字段及问题明确指定的单字段反事实外，不存在其他人员、岗位、资格轨迹、卡片轨迹、档案序列、门流动作、控制器行或自由修复。若某个问题只改变完全匹配事件行的通道字段，必须保留原事件行的其他四项封存字段，并从头重算事件关联、权限、会话和四份核验栏，不能改用维护自检或其他近似记录。
