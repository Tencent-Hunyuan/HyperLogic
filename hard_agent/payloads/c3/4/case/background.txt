本次赛事的封闭名单只包含八支成年一队。第一档由 A 战队、D 战队、E 战队和 G 战队组成，第二档由 B 战队、C 战队、F 战队和 H 战队组成。赛事连续举行三个有标签的比赛日。每天必须安排四场第一档对第二档的比赛，每支队伍每天恰好参赛一次，同一对跨档对手在三个比赛日内不得再次相遇。青年队、预备队和名单外队伍既不占比赛席位，也不占任何转场或转播资源。

赛区登记把 A 战队列入东区，把 D 战队与 F 战队列入西区，把 E 战队列入中区，把 G 战队列入海岸区，把 B 战队列入北区，把 C 战队列入南区，并把 H 战队列入高原区。因此，名单内唯一同区的跨档组合是 D 战队与 F 战队。规避规则规定，同区组合不能参赛；两支成年一队若在首个比赛日前十二个月内参加过正式比赛，也不能在三个比赛日中的任何一天相遇。正式档案另记载，G 战队与 B 战队在五个月前参加过成年一队正式比赛。除此之外，只有 A 战队与 C 战队的异常记录可能触发近期交手规避。

A 战队与 C 战队八个月前确曾以成年一队身份交手，但赛事性质字段无法恢复。必须保留两个且仅有两个互斥而穷尽的分类。一个分类把该场认定为窗口内成年一队正式比赛，另一个分类不把它认定为此类正式比赛。前一分类禁止 A 战队与 C 战队相遇，后一分类不因该记录禁止两队相遇。两个分类中的日期、参赛主体、赛区、可用窗和其他资源规则完全相同。另有一场四个月前的 A 战队青年队与 C 战队青年队正式比赛；该记录主体明确，不会触发成年一队规避。

三个场馆分别是河湾馆、山脊馆和港城馆。山脊馆分别与另外两个场馆相邻，河湾馆与港城馆不相邻。每天设晨场、午场、晚场和夜场四个有标签时段，每个时段恰好承载一场比赛。场馆可以在不同的时段重复使用，也可以整日不被使用；任何比赛都必须同时取得双方队伍的时段资格和场馆资格。在下列逐日清单中，同一支队伍列出的时段与场馆可以自由组合，未列出的时段或场馆一律不可使用。

第三比赛日，A 战队可使用午场、晚场和夜场，可使用山脊馆或港城馆。D 战队可使用晨场、晚场和夜场，可使用山脊馆或港城馆。E 战队可使用晨场、午场和晚场，可使用河湾馆或港城馆。G 战队可使用晨场、午场和夜场，可使用河湾馆或山脊馆。B 战队可使用午场、晚场和夜场，可使用山脊馆或港城馆。C 战队可使用晨场、午场和夜场，可使用河湾馆或港城馆。F 战队可使用晨场、午场和夜场，可使用河湾馆或山脊馆。H 战队可使用晨场、午场和晚场，可使用山脊馆或港城馆。

每支队伍在第一日与第二日之间以及第二日与第三日之间各有一次转场，共形成十六次相邻比赛日转场。如果一支队伍更换场馆且下一场安排在晨场或午场，该次转场属于合格加急转场；其他转场均为普通转场。合格加急转场不能改用普通方式，普通转场也不能占用加急许可。整套赛程中必须恰有四次合格加急转场。

赛事只有四张具名加急许可，分别是晨桥许可、午岚许可、山径许可和联程许可。晨桥许可只能用于下一场为晨场的合格转场。午岚许可只能用于下一场为午场且至少一端位于山脊馆的合格转场。山径许可可以用于任何一端位于山脊馆的合格转场。联程许可只能用于第二比赛日结束后的合格转场。每张许可在整项赛事中只能正式锁定一次，每次合格加急转场必须锁定一张适用且尚未使用的许可。由于全局配额要求恰有四次合格加急转场，四张许可在有效完整世界中都会被正式使用，不允许空置、借用或重复登记。若同一转场符合多张许可的范围，选用不同具名许可会形成不同的完整世界。

同一支队伍最多进行一次合格加急转场。如果一支队伍在第一段使用了加急许可，那么它在第二段不得再次使用加急许可；若第二段还要更换场馆，其第三日比赛只能安排在晚场或夜场。若第二段留在原场馆，则第三日仍可使用晨场或午场。这项恢复规则与许可配额同时生效。

四支具名移动转播机组分别是北斗机组、云雀机组、松柏机组和潮汐机组，其中北斗机组与云雀机组属于高级机组。每天每场比赛恰由一支机组承办，每支机组每天恰好承办一场。第一比赛日开始前，北斗机组与潮汐机组位于河湾馆，松柏机组位于山脊馆，云雀机组位于港城馆；第一日的承办场馆必须与各机组起点一致。

相邻比赛日之间，机组留在原场馆始终可行。河湾馆与山脊馆之间以及山脊馆与港城馆之间的相邻转移通常可行；若前一场为夜场且次日承办晨场，则只有北斗机组或云雀机组可以完成该相邻转移。河湾馆与港城馆之间的直接转移在基线中只对北斗机组和潮汐机组开放，并且要求前一日承办晨场或午场、次日承办晚场或夜场。除此之外不得直接跨越河湾馆与港城馆，也不得把中途停靠当成两个独立可用位置。第三比赛日结束时的场馆库存由 A 战队在第二比赛日的实际对手决定。若该对手是 F 战队，河湾馆必须留有一支机组，山脊馆必须留有一支机组，港城馆必须留有两支机组。若该对手不是 F 战队，也就是该日对阵其余任何合法对手，河湾馆必须留有一支机组，山脊馆必须留有两支机组，港城馆必须留有一支机组。两种库存条件互斥且穷尽，适用哪一种只由实际对手确定，不设置可另行选择的库存标签，也不预先指定各场馆留下的是哪支具名机组。机组每日结束位置就是当日承办场馆，转出与转入必须追踪同一具名机组。是否满足适用库存必须按四支具名机组的实际第三日终点核验，不得每日重置或瞬移。

松柏机组曾持有一份河湾馆与港城馆之间的直接通行许可，但该许可在首个比赛日前已经失效。它与现行路线使用相同的机组名称和场馆名称，却不能支持任何基线机组转移；只有后文修订目录明确续期时才重新生效。

黄金转播场不是自由标签，而是由比赛事实推导。第一比赛日的指定场馆是河湾馆或港城馆，第二比赛日的指定场馆是河湾馆或山脊馆。第三比赛日，港城馆始终是指定场馆；当 D 战队第三日的实际对手是 H 战队时，山脊馆也属于指定场馆；当其实际对手不是 H 战队时，山脊馆不属于指定场馆。在基线中，第三比赛日的指定场馆只按这一实际对阵关系确定，该关系不是可另行选择的状态，也不形成额外的完整世界重数。一场比赛只有同时位于当日指定场馆、安排在晚场或夜场、并由北斗机组或云雀机组承办时，才属于黄金转播场。使用封闭式规避豁免的比赛即使满足这三个条件也不计为黄金转播场。十二场比赛中必须恰有五场黄金转播场。

赛前审计保存了四份具名通告。海岬通告称，A 战队与 C 战队的异常记录被认定为窗口内成年一队正式比赛；A 战队第二日的对手是 F 战队或 H 战队；该场安排在第二日的指定黄金场馆并处于晚场或夜场；承办该场的是高级机组。联港通告称，异常记录不被认定为窗口内成年一队正式比赛；A 战队第二日的对手是 C 战队或 F 战队，而且这一对手子句是封闭的，不包括其他战队；该场安排在河湾馆的晚场或夜场；北斗机组承办该场。夜航通告称，A 战队第一日对阵 B 战队；该场位于港城馆夜场；云雀机组承办该场；A 战队从第一日到第二日采用普通转场。终场通告称，D 战队第三日的对手是 B 战队或 H 战队，而且这一对手子句是封闭的，不包括其他战队；该场位于山脊馆或港城馆，并安排在晚场或夜场，所列场馆和时段范围也都是封闭的；该场由两支高级机组中的一支承办；两支高级机组中的另一支在第三日结束时位于山脊馆与港城馆中没有承办该场的另一座场馆。

一份通告只有在其中所有断言都准确时才算整份准确。整份通告不准确只表示至少一项断言不准确，并不表示其中每项都错误。四份通告中必须恰有两份整份准确。通告真值由记录分类、对手、时段、场馆、许可、机组和终场位置共同推导，不是可以另行选择的状态。终场通告列出的备选范围只用于核对完整世界中的实际对手、场馆和具名机组，不设置可另行选择的通告标签。

一个基线完整世界必须同时满足四项全局条件：十二场比赛中恰有五场黄金转播场，十六次队伍转场中恰有四次合格加急转场，四份通告中恰有两份整份准确，并且四支具名机组从固定起点沿允许路线守恒移动到由 A 战队第二日实际对手确定的第三日场馆库存。黄金配额直接共享 D 战队第三日的实际对手以及比赛时段、场馆和具名机组，加急配额直接共享比赛时段、场馆和具名许可。D 战队第三日是否对阵 H 战队决定山脊馆是否具有当日的指定资格，终场通告则同时核对该队第三日的对手、比赛位置、承办该场的高级机组以及另一支高级机组的终点。黄金配额与机组守恒还共享同一批具名机组，条件化终场库存又把 A 战队第二日的实际对手与四支机组的第三日终点直接连接起来。所有满足全部规则的世界等价保留，不设优先级。

一个完整世界保留异常记录分类、三个比赛日的十二组对阵、每场的有标签时段与场馆、每次队伍转场的普通状态或具名许可、每场的具名机组以及各机组的跨日位置。适用的终场库存由完整世界中 A 战队第二日的实际对手确定，再以其中四支具名机组的实际终点核验；库存条件不是独立状态，也不额外制造重数。相同赛程若使用了不同的适用许可或不同的具名机组补全，属于不同完整世界；相同的其余安排若处于两个不同记录分类，也属于不同完整世界。黄金属性与通告真值只是派生结果，不额外制造重数。

赛程骨架只保留三个比赛日的对阵、场馆和有标签时段，抹去记录分类、队伍许可和具名机组。某个骨架只有在相应记录分类下至少拥有一个满足全部全局条件的完整补全时，才进入该分类的骨架投影。两个分类下出现同一骨架时，各自投影中都只保留一次。任何投影都必须在许可、通告和机组守恒已经检验完毕后进行，不能先按比赛日或按单场投影再拼接。

修订评估使用一个固定焦点赛程包。该包要求第一比赛日由 A 战队与 B 战队在港城馆夜场比赛，并由云雀机组承办；第二比赛日由 A 战队与 C 战队在河湾馆夜场比赛，并由北斗机组承办；第三比赛日的晨场是河湾馆的 G 战队对 C 战队并由潮汐机组承办，午场是山脊馆的 A 战队对 F 战队并由松柏机组承办，晚场是港城馆的 E 战队对 H 战队并由北斗机组承办，夜场是山脊馆的 D 战队对 B 战队并由云雀机组承办。焦点包没有指定的第一日和第二日其他比赛仍须按全部规则补全，焦点包中已经指定的对手、时段、场馆和机组则不得挪动。焦点包已经把 A 战队第二日的实际对手固定为 C 战队，因此其终场库存按前述适用于其余合法对手的条件核验。

修订候选域是以下十四项具名目录，未列出的事实不能修改。第一项称为封闭式单场豁免，它允许焦点包中的 A 战队与 C 战队比赛绕过正式比赛规避，但该场在两个记录分类下都带有封闭式豁免标记，因此不能成为黄金转播场。第二项称为联合保障备案，它把该场登记为获准复赛；即使异常记录被认定为正式比赛，该场也不触发规避，而且不带封闭式标记；同一不可拆分的备案还把 A 战队列入第二段联程许可的可用队伍。第三项称为 C 战队夜窗增开，它在保留原有资格的同时增加 C 战队第二日夜场资格，场馆范围仍是河湾馆或山脊馆。第四项称为联合可用窗校正，它同时增加 C 战队第二日在河湾馆使用夜场的资格，并增加 B 战队第二日在其原有时段使用山脊馆的资格，这两项更正不可拆分。第五项称为封闭联运试行，它增加 C 战队第二日在河湾馆夜场的资格，并向高级机组开放河湾馆与港城馆之间的连续日直接转移，只要次日不是晨场即可使用；凡焦点包借助该试行安排 A 战队与 C 战队比赛，该场带有封闭式标记。

第六项称为河港夜间走廊恢复，它向北斗机组与云雀机组开放河湾馆与港城馆之间的连续日直接转移，只要次日不是晨场即可使用，不改变队伍可用窗。第七项称为北斗专线，它只允许北斗机组在第二日河湾馆夜场结束后，于第三日转到港城馆晚场，不改变云雀机组或其他路线。第八项称为松柏许可续期，它只恢复松柏机组已经失效的河湾馆与港城馆直接许可，并沿用基线对前后时段的限制。第九项称为联港对手子句校正，它把联港通告中整个“A 战队第二日的对手是 C 战队或 F 战队”封闭子句收紧为“A 战队第二日的对手是 F 战队”。第十项称为联港场馆子句校正，它把联港通告中整个“该场安排在河湾馆的晚场或夜场”子句替换为“该场安排在山脊馆夜场”。第十一项称为联港机组子句校正，它把联港通告中的北斗机组断言改为云雀机组。

第十二项称为联程许可扩展，它允许联程许可也用于第一段合格加急转场，其他三张许可的范围不变。第十三项称为首日起点互换，它交换松柏机组与潮汐机组在第一比赛日开始前的位置，北斗机组与云雀机组的起点不变。第十四项称为第三日黄金场馆增补，它无论 D 战队第三日的实际对手是谁，都把山脊馆加入第三比赛日的指定黄金场馆；港城馆仍然保留指定资格。

选中的修订同时作用于两个异常记录分类，未选中的字段保持基线取值。多项修订的效果累计适用；封闭式标记一旦由第一项或第五项产生，不会被其他修订自动消除。一个修订子集只有在采用同一组修订后，焦点赛程包分别能在两个记录分类下各扩展成至少一个完整世界时才算成功；两个分类所用的其余补全可以不同。成功判定仍须检查全部十二场比赛、两段队伍转场、四张具名许可、五场黄金配额、两份准确通告以及三日机组守恒。修订集的比较只按所含目录项数量进行，不能把找到一个充分方案当成已经找到最小方案。
